# Starry-Reading-Tracker

## About the Project
Starry Reading Tracker is a web application created to help users discover books and keep track of their reading activities. 
Users can search for books using an external API, create personal reading lists, and share reviews with other users.

## Features
* Book search using API
* Reading list management
* Book reviews and ratings
* User-friendly interface

## Technologies Used
* HTML
* CSS
* JavaScript
* Node.js
* REST API
